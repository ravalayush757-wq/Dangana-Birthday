============================================================
  THE ROYAL GALLERY — Instructions for Adding Photographs
============================================================

To add photographs to the Royal Gallery:

1. Place your photo files (JPG, PNG, WEBP) into this "photos" folder.

2. Open the file "js/gallery.js" and find the "photos" array at the top.

3. Add entries like this:

   photos: [
     { file: 'photo1.jpg', caption: 'A Treasured Memory' },
     { file: 'photo2.jpg', caption: 'Together in Joy' },
     { file: 'photo3.png', caption: 'A Moment of Bliss' },
   ],

4. Save the file and refresh the website.

Each entry needs:
  - file:    The exact filename of the photo (including extension)
  - caption: A short description (shown on hover)
